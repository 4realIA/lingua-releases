# Lingua

Grammar lessons, drills and flashcards for Russian and Korean.

This repository holds only Lingua's finished installers and its update feed.
Installed copies of Lingua check here for new versions.

## Install

Open the **[latest release](https://github.com/4realIA/lingua-releases/releases/latest)**
and download, from **Assets**:

- **Windows:** `Lingua_<version>_x64-setup.exe`. If Windows shows "Windows
  protected your PC", choose **More info → Run anyway**.
- **Mac:** `Lingua_<version>_universal.dmg`. Drag Lingua to Applications. The
  first time, right-click Lingua and choose **Open**.

After that, Lingua offers new versions itself (**Settings → Updates**).

## Privacy

Lingua collects nothing. See the [privacy policy](PRIVACY.md).

## Help

Open an [issue](https://github.com/4realIA/lingua-releases/issues), or use
**Settings → Copy support info** in Lingua and send it to whoever set it up
for you.
